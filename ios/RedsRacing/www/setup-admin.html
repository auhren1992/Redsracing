How admin access works

Admin privilege is granted only through Firebase Auth custom claims (via the setAdminRole Cloud Function). Writing role / isAdmin on a Firestore user document no longer grants access.

  1. Sign in as auhren1992@gmail.com for the one-time bootstrap, or as an existing admin.
  2. Click Request Admin via Cloud Function.
  3. Sign out and back in (or refresh the ID token) so the new claim is picked up.
